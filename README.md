## ❯ Engineering Philosophy

I build systems that are **predictable, secure, and resilient**. I believe AI should augment deterministic architecture, not replace it. My work focuses on building the infrastructure that makes complex AI and data operations safe and reliable.

> **Core Tenets:**
> - **Zero Data Leakage:** PII and credentials must be sanitized *before* they hit the network.
> - **Deterministic Foundations:** Core business logic must be verifiable and consistent.
> - **Test-Driven Reliability:** If it's not tested, it's technical debt.
> - **Performance by Default:** Leverage C++ for critical paths, Python for orchestration.

## ❯ Featured Architecture & Systems

### [LogSense-AI](https://github.com/VasudevTripathi/LogSense-AI) — *Autonomous AI Log Diagnostics*
A production-ready incident analysis engine that parses unstructured system logs, redacts sensitive data locally, and utilizes LLMs for root-cause analysis.
* **Impact:** Prevents PII leakage to third-party AI APIs while providing actionable debugging insights.
* **Architecture:** FastAPI backend, local Regex/Pattern sanitization pipeline, OpenAI integration, SQLite storage.
* **Verification:** 26 automated unit tests ensuring 100% redaction compliance.
* **Stack:** `Python` `FastAPI` `React` `Pytest`

### [TriageCare](https://github.com/VasudevTripathi/TriageCare) — *ER Operations Simulator*
A high-throughput clinical operations triage simulator prioritizing emergency room patient streams.
* **Impact:** Demonstrates advanced priority queue management under high capacity with strict tie-breaking logic.
* **Architecture:** Core C++17 engine synchronized to a stateless React web dashboard via encoded URL state.
* **Verification:** Dual-channel parity testing between C++ logic and frontend state.
* **Stack:** `C++17` `JavaScript` `React`

### [Civora Compliance OS](https://github.com/VasudevTripathi) — *Deterministic Workflow Engine*
A decision layer transforming complex regulatory requirements into structured compliance roadmaps.
* **Impact:** Automates compliance tracking using topological graph resolution.
* **Architecture:** Dynamic programming critical path calculation, topological step scheduling (`AVAILABLE`/`BLOCKED`).
* **Stack:** `Python` `FastAPI` `Graph Algorithms`

### [Dynamic Memory Management Visualizer](https://github.com/VasudevTripathi/Dynamic-Memory-Management-Visualizer)
An interactive system tool illustrating OS dynamic memory allocation strategies (First/Best/Worst/Next Fit) and heap fragmentation behavior.
* **Stack:** `C++` `JavaScript` `HTML/CSS`
